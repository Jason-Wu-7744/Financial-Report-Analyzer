## 回归结果

**296 个测试通过，另有 8 个 unittest 子测试，耗时 35.91 秒。**

```text
python -m pytest tests -q
```

测试工作目录和 JUnit 报告位于发布目录之外。受限沙箱内 asyncio socketpair 无法初始化，因此 Streamlit AppTest 在沙箱外执行；完成的测试包含界面工作流，没有跳过这些测试。

覆盖范围：

- PDF/证据选择和财务主表连续性。
- 会计口径和受限现金证据回归。
- 报告结构、异常响应、引用页检查和重试状态。
- 风险触发结果与证据不足分别表示。
- 数字和引用保护、英文导出及原文产物保持不变。
- 后台任务去重、不含密钥的请求保存和失败阶段恢复。
- 双语登录、输入、公司卡片及已保存报告工作流。
- 环境配置账号、非法配置拒绝，以及缺少配置时没有启用账号。

## 验证边界

本次回归没有调用付费模型、重新下载官方财报、独立核验所有保存样例的财务结论，或测量端到端生成延迟。模型相关用例使用受控响应。通过测试只证明对应行为，不代表经审计的财务准确率或生产部署就绪。

README 中的界面图片是原源码材料中的历史 QA 截图，发布前检查了可见个人姓名与凭据；它们不是本次回归生成的截图。公开账号配置与原部署不同。
