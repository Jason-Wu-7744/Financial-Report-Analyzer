# 财报筛选与分析系统 · v8.1：研究方法

[English](RESEARCH_METHOD.md) · [中文首页](../README.zh-CN.md)

系统面向 A 股与港股上市公司，将官方财报检索、经营快评、附有证据的研究简报和结构化风险核验连接起来。界面保持左侧公司卡片、右侧报告与进度；封面使用压缩本地图片，公司卡片保留业务实质描述，移除了杜邦指标。

## 研究流程

1. **取得并验证正式财报。** 从 CNINFO 或 HKEX 检索，区分完整报告、摘要及业绩公告，并检查主体与报告类型。
2. **跨文档选择证据。** 规范 PDF 文本，定位主表、分部和重要附注，保留物理页码。在分配其余文本预算前保留完整主表及续页。主题覆盖仅是检索诊断，不能证明财务事实。
3. **解释重要经营变化。** [应用分析指令](../analyzer/SKILL.md)要求七章 Markdown 简报：研究结论；经营驱动与盈利质量；资产、现金与债务；风险与反证；情景与跟踪；关键数字与会计核验；证据及局限。目标是简洁研究，而非逐行抄录。
4. **保持会计边界。** 明确币种、单位、期间、合并范围，以及报告/固定汇率/调整口径。港股非公认会计准则利润与内地扣非净利润分别处理。银行、保险使用行业专属证据。
5. **缺证据不等于风险清除。** 每项独立核验区分已核验未触发、已核验触发、证据不足和不适用。研究简报中的风险事实及待验证风险，与十九条硬规则结果分别表示。披露减值不自动等于触发硬风险规则。

## 可靠性与英文

缺失或中断章节采用有界定向修复。引用页检查限于实际提供给模型的页面。已有现金流桥不能未经纠正或明确可重试状态就被描述为缺失。未完成生成、测试模式、缺少密钥或语言检查失败不属于已完成研究。

英文由原语言分析翻译，并检查数字、保护引用、会计术语及结论强度。原文和英文分别存储。译文摘录标明翻译，不当作英文原文引述。英文公司表同时显示中文主体名称，辅助证券识别。

**这些检查不能证明经审计的准确率。** 引用页存在不代表支持推断；报告完整不代表数字和结论全部正确。抽取可能遗漏版式与附注，模型可能误解事实、比较口径或因果关系。重要数字、比率、引用及结论需要回到原财报核验。没有人工审阅时，系统不得声称已经人工审阅。

现金桥仍是需要分析师复核的模型计算。v8.1 以 Decimal 独立检查显式展示的加减算式，不核验未展示计算、来源语义、现金流分类或币种/单位换算。算式错误或将母公司利润作为合并业绩，会使报告进入可重试核验状态。章节、表格完整性及引用页可用性分别检查。原表舍入差异应披露，不修改来源数字。

报告写明期间、分析日期及证据局限。历史财报不是当前投资观点；没有一致预期、价格或预测数据时，不虚构预期、目标价或估值输入。

## 保存工作与样例

报告在后台生成，保存进度与每家公司检查点。研究历史支持返回失败阶段继续，中文和英文产物分开保存。

[样例清单](../samples/manifest.json)列出只读历史样例，记录公司、期间、语言、生成时间及实际校验范围。历史样例不是实时计算，也不能当作新生成的耗时证明。仅已完成最终 QA 的样例进入清单；空或待完成清单不表示存在已完成样例。

## 本地运行与验证

完整安装及账号配置见[中文首页](../README.zh-CN.md)。启动后 `?lang=en` 选择英文，`?lang=zh` 选择中文。新模型生成与动态翻译需要有效服务连接；测试或演示输出不构成研究结论或风险清除。

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

确定性回归覆盖抽取、报告修复、来源引用、证据状态、英文检查、后台恢复及双语工作区。真实 API 测试与浏览器检查单独开展。回归通过不等于财务准确率或通用性能结论。最终 QA 与样例清单记录特定版本的真实运行证据；耗时受下载、缓存、模型、修复和翻译影响。
