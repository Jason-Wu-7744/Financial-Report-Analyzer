# 证据标准与边界口径

## 目录

- 来源优先级
- 截止日与时点
- 逐项证据最小集
- 计算口径
- 易错边界

## 来源优先级

1. 公司法定公告、交易所披露、经审计年报、监管处罚决定。
2. 政府、司法、纪检监察、行业主管部门和官方统计。
3. 可靠金融数据库/交易行情，用于价格、成交额、估值分位、股东和标准化指标。
4. 可信行业协会、龙头公司公告和研究机构，只作行业交叉验证。
5. 新闻与二手资料仅作线索，不单独支撑致命结论。

对“未发现”类结论，写清检索范围、数据库/官网、覆盖期间和查询日期。搜索不到不等于事实不存在。

## 截止日与时点

- 只使用排雷日当日已公开资料；若排雷发生在交易日收盘前，行情默认取前一完整交易日并说明。
- 区分报告期、公告日和访问日。业绩预告、快报、未经审计季报必须标注性质。
- 不用排雷日之后的公告反向影响当时结论。

## 逐项证据最小集

- H1-H2：3-5年行业量/价趋势、最新周期信号、技术替代证据、现行政策与监管方向。
- C1：三年审计意见；现金、资产、有息负债和利息；其他应收与关联购销；三年 OCF/净利；公司/实控人监管记录。
- C2：未受限现金、合格短期金融资产、短期有息债务、授信可用额、最新 OCF、质押、占用与担保。
- C4：公司公告、监管/司法/纪检官方文件；明确人员身份、任职时点和法律阶段。
- C5-C6：同一复权口径的历史估值分位与区间涨跌；亏损公司不要使用负 PE 作为估值证据，可改用 PB/PS/EV 指标并说明。
- C7-C10：分部收入、订单/交付、客户验证、资本开支、研发投入、分红回购、技术替代、催化剂和经营周期。
- C11/Q4：ST/退市状态、20日日均成交额、商誉、净资产、业绩承诺期。
- Q1-Q6：至少3年，趋势项优先5年；账龄、减持和估值必须满足框架的 AND 条件。

## 计算口径

- 有息负债率 =（短期借款 + 一年内到期有息负债 + 长期借款 + 应付债券等有息项）/ 总资产。披露不足时列示采用项。
- FCF = 经营活动现金流净额 - 购建固定资产、无形资产和其他长期资产支付的现金。
- 短债覆盖 =（未受限现金及现金等价物 + 可即时变现的合格短期金融资产 + 明确可用授信）/ 一年内有息债务。不得把受限资金全额计入。
- 三年利润质量 = 三年累计 OCF / 三年累计归母净利润。分母≤0时不计算百分比。
- 应收强度 = 期末应收账款账面余额或账面价值 / 当期营收；必须标明采用哪一种。
- 区间涨跌使用复权收盘价，注明起止交易日。
- 所有比率保留可复算的分子、分母与单位；同比和百分点不要混用。

## 易错边界

- AND 条件不拆开命中。例如 Q1 需要“>80%”和“连续两年上升”同时成立。
- Q3 负分母不是低于50%，而是无经济意义；持续亏损属于黄灯或其他检查项证据。
- 行业竞争激烈、公司份额下降，不等于 H1 行业不可逆萎缩。
- 政策补贴下降、监管趋严，不等于商业模式归零。
- 有真实产品、订单或交付可否定“纯概念”，但不能自动证明盈利与资本回报。
- 历史高管事件是否命中 C4 必须遵循框架统一口径；若要限定现任高管或生效判决，应先书面修改框架并对所有公司一致适用。
- 非标审计意见需区分保留、否定、无法表示和带强调事项的无保留意见，并按框架原始口径说明。
- 淘汰后仍可列低成本跟踪项，但不得继续包装成常规深度研究建议。
