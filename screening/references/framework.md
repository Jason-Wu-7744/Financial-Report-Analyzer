## 定位与原则

仅过滤可能导致本金永久损失的致命伤害，不做全面公司评价。任一致命项已核验触发即一票否决，不评分。排雷顺序为行业→公司→定量。每项证据状态为“已核验未触发、已核验触发、证据不足、不适用”；无触发但尚有证据不足时整体为待补证，不能称全部通过。仅当适用期间、口径、来源及阈值条件完整核验后才可判未触发；未查到、未披露和候选页未覆盖均不等于通过。

## 第一层：行业致命风险

| ID | 检查项 | 命中标准 |
|---|---|---|
| H1 | 行业需求不可逆萎缩 | 行业整体需求连续下滑、无周期复苏信号，且技术替代不可逆。 |
| H2 | 行业面临政策致命风险 | 行业商业模式合法性存疑；核心收入依赖单一政策容忍度，一纸文件可归零。 |

## 第二层：公司致命风险红线

| ID | 检查项 | 命中标准 |
|---|---|---|
| C1 | 财务真实性存疑 | 任一命中：①货币资金/总资产>20% 且有息负债率>40%，并出现利息收支不匹配；②其他应收款/净资产>20%且去向不明，或关联采购/销售占比>30%且定价不公允；③最近3年审计非标；④近3年累计经营现金流净额/累计净利润<50%且无合理解释；⑤公司或实控人有财务造假、重大信披违规被立案处罚前科。 |
| C2 | 资金链断裂风险 | 任一命中：①短期有息负债>货币资金+未受限银行授信，且经营现金流为负；②大股东股权质押>70%（>80%极端）；③大股东资金占用、违规担保或掏空上市公司有实锤。 |
| C3 | 政策一招致命 | 核心业务合法性完全依赖单一政策容忍度，政策转向业务归零；或行业已被明确限制/禁止且政策底部不明。 |
| C4 | 管理层诚信缺陷 | 任一命中：①实控人/高管有财务造假、内幕交易、行贿等违规前科、刑事犯罪记录或重大失信被执行记录；②存在低价定增输送、高位精准减持、忽悠式重组、承诺屡次不兑现等损害小股东利益实锤；③核心管理团队1年内集体离职。 |
| C5 | 极度高估 | 估值处于自身历史90%分位以上，且无足够业绩增长支撑，隐含增速已透支两年以上业绩。 |
| C6 | 短期暴涨 | 近6个月涨幅>80%，或近3个月>100%，或近1个月>50%，且无基本面重大变化支撑。 |
| C7 | 价值陷阱 | 按原框架逐一核验：主营业务连续2年营收、归母净利双下滑且行业需求不可逆萎缩、无周期反转；或核心业务被技术/政策彻底颠覆且无转型能力；或现金充沛但连续5年不分红不回购；或未来12-18个月无可名状催化剂。不要把“便宜”当作通过证据。 |
| C8 | 次新股 | 上市不满2-3年，财务包装期、解禁减持和完整周期检验尚未结束。框架原文为直接排除。 |
| C9 | 资本黑洞 | 收入利润多年无增长，同时资本开支/折旧比长期>1.5，且自由现金流常年为负。三项组合条件要按“同时”理解。 |
| C10 | 纯概念蹭风口 | 热点业务真实收入占比<20%，且依靠公告/互动易蹭概念，并缺乏订单、客户验证、资本开支等落地证据。真实产品/交付可以否定“纯概念”，但不等于证明盈利。 |
| C11 | 流动性与退市风险 | 任一命中：①已被实施 ST/*ST 或存在明确退市风险；②日均成交额<5000万元；③商誉/净资产>50%且业绩承诺集中到期、大概率无法兑现。 |

## 第三层：关键定量底线

| ID | 检查项 | 命中标准 |
|---|---|---|
| Q1 | 资产负债率红线 | 资产负债率>80%，且连续2年持续上升。 |
| Q2 | 现金流红线 | 连续3年经营现金流净额为负，且主业无周期反转逻辑。 |
| Q3 | 利润质量红线 | 近3年累计经营现金流净额/累计净利润<50%。累计净利润≤0时分母失效，标为“通过（不适用）”，并把持续亏损另列黄灯。 |
| Q4 | 商誉暴雷风险 | 商誉/净资产>50%，且标的公司业绩承诺期集中到期。 |
| Q5 | 应收账款恶化 | 应收账款/营收>40%，且1年以上账龄占比>30%。 |
| Q6 | 大股东减持信号 | 近1年大股东/实控人减持>总股本5%，且估值处于历史中高分位。 |

## 结论与归档

- 19项全部通过：结论“通过”，可进入深度研究。
- 任一项高风险：结论“淘汰”，归档并冻结6个月；其他通过项不得抵销。
- 归档编号建议：`公司简称-F-YYYYMMDD-命中ID`。同一公司6个月内不重复消耗常规研究资源。
- 每季度复盘否决标的库并校准阈值，但不得为单一公司临时豁免。
