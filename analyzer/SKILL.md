# 财报研究备忘录 v8.1

读者需要在几分钟内理解：什么发生了变化、为什么重要、证据有多强、什么会改变判断。先按 [规则](rules.md) 核实口径，再按 [七章模板](report_template.md) 交付。行业或公式问题参考 [研究方法](references/research-methods.md)。不把研究报告写成逐科目复述或投资推荐。

1. 确认主体、报告实际期间、币种/单位、合并范围、准则、审计/审阅状态。港股不全部称H股；本公司拥有人应占利润、合并利润、非GAAP调整利润分别处理。
2. 对程序选出的本期和历史页建立证据账本。只有实际输入页才可引用；用 [本期PDF第N页] / [上期PDF第N页] 标识物理页和文件。输入覆盖说明仅是取证诊断，不能写成全部事实已核验。
3. 选择最重要的两到三项变化。每项用“事实与可比基数 → 经营机制 → 判断 → 反证/验证条件”连接；优先收入/分部、利润质量、现金/债务，不以固定涨跌幅替代经济重要性。
4. 用三表及附注互证。区分经营驱动和一次性损益、利润与现金、自由现金与客户/受限资金。只计算输入齐全、口径一致的指标，展示公式；缺参数给定向补证问题。
5. 行业适配：银行看净息差、信用成本、不良与资本/流动性，保险看保险服务结果、CSM与偿付能力，其他行业看量价/结构、营运资本和资本开支。证据不支持的工业指标直接省略。
6. 将风险程度与证据充分度分开。深度报告标识“已观察到的风险事实 / 未来风险尚待验证 / 证据不足”；减值、信贷成本或经营压力事实不自动代表硬风险规则触发。独立排雷报告负责十九项规则及其四态，本报告不使用“已核验触发/已核验未触发”替代研究判断。异常先列替代解释，不能推断造假。
7. 输出七章 Markdown，目标约1800–2600个汉字，信息密度优先，材料充分时可略长。最多三张短表，每表最多六行；不要同时堆积预测、估值与市场反应。无行情、共识和假设时只给可验证的情景传导与跟踪项，不给目标价。
8. 交付前检查章节、表格闭合、引用页存在、期间/币种和论证强度；英译须保留“可能/尚未核验”等限定语。第六章区分“模型读取与原文定位”“程序页码/算术检查”“待人工复核”；没有实际程序计算记录，不声称算术已由程序通过。没有人工审阅记录，不写“已核对原文”或暗示人工逐项核查。

业务实质卡片的原有写作风格不属于本技能的修改范围。历史十二章报告可读取，新生成报告采用本模板。
